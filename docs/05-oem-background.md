# Фон и автозапуск — ограничения Android

## Что используем
Всё — `ForegroundService` с постоянным уведомлением. Единственный честный способ пулить каждые 10с с потухшим экраном (без Doze-душа). Сервис объявлен как `START_STICKY`.

## Автозапуск
`BootReceiver` ловит `BOOT_COMPLETED`. При буте читает `SharedPreferences.isRunning` — если было включено до перезагрузки, стартует сервис снова.

Дополнительно (если добавишь): `QUICKBOOT_POWERON` (некоторые прошивки), `LOCKED_BOOT_COMPLETED` (до разблокировки) — не стали делать минималку, но легко добавить.

## OEM-подводные камни
| Производитель | Что делает | Как чинить |
|---|---|---|
| Xiaomi/MIUI | «Автозапуск» выкл по умолчанию, сервис гасит | Настройки → Приложения → PumpSms → Автозапуск вкл; Батарея → Без ограничений |
| Samsung | «Оптимизация батареи» гасит | Батарея → Фоновая активность → Разрешить |
| Huawei/Realme/OnePlus | Агрессивные киллеры | То же + «Защита от очистки» |
| Stock Android | Doze | ForegroundService держит вайфлком, ок |

## Советы
- На экране показать подсказку «Если сервис отваливается — включите Автозапуск в настройках».
- При тестировании наотухшем экране: не убивать приложение свайпом из меню задач, при гашении — сервис остаётся (проверяется по иконке уведомления).
