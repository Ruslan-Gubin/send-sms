# PumpSms — план проекта

## Цель
Личное Android-приложение для автоматической отправки SMS. Устанавливается файлом (APK), работает в фоне и с потухшим экраном, пулит бекенд каждые 10 секунд и отправляет SMS по задачам из очереди.

## Контекст
- Платформа: **только Android** (версия устройства: Android 13 TP1A.220624.014)
- Установка: sideload APK, личный инструмент, не публикуется в Play Store
- Бекенд: тот же, что в `shop` — `http://192.168.x.x:4010` (пока локальный ПК, потом адрес меняется в `Config.kt`)
- Язык UI: русский
- Одна страница, без дальнейшей эволюции
- На текущем этапе: 1 SIM по умолчанию, в будущем — маршрутизация по операторам

## Флоу (ТЗ 1-9)
1. Запуск приложения
2. Ввод номера телефона устройства — ручной или нативный модуль `getLine1Number()` (best-effort, часто пусто). Сохраняется в `SharedPreferences`
3. Нажатие «Старт» — запускается `ForegroundService` с пульсом 10с
4. Если есть задача — **останавливаем пулинг** (цикл ждёт окончания отправки), отправляем SMS на номер из задачи
5. Успех — `POST /sms/outbox/:id/delivered` → статус `delivered`
6. Ошибка — `POST /sms/outbox/:id/failed { error_code, error_reason }` → `failed*` (+ причина)
7. После успеха/ошибки — **снова пулинг** за задачами
8. Проверка интернета — если нет, на бекенд не ходим, пишем в лог
9. Работа в фоне — с потухшим экраном (ForegroundService + автозапуск)

## Стек
- **Kotlin + Jetpack Compose (Material3)** — 1 экран
- **Retrofit 2 + OkHttp + Gson** — 3 эндпоинта (GET/POST/POST)
- **Coroutines` + `StateFlow`** — цикл пулинга, лог
- **SmsManager** + `BroadcastReceiver` (sent/delivery PendingIntent)
- **ForegroundService** + `BootReceiver` (автозапуск) + `Notification`
- **SharedPreferences** (номер устройства, состояние вкл/выкл)
- **ConnectivityManager** — проверка интернета
- **TelephonyManager** — best-effort номер устройства (`READ_PHONE_STATE`)

## Почему не RN / не C++
- **C++** — невозможен: SMS/сервисы/пермишены — Java/Kotlin-фреймворк, C++ лишь через JNI.
- **RN** — 80% кода всё равно нативный (служба, SMS, статус доставки). RN даёт лишь 1 экран, но тянет 30–50МБ APK против ~8–10МБ у Kotlin.

## Ограничения
- `READ_PHONE_STATE`/`SEND_SMS` — опасные пермишены, но для личного APK без публикации ок.
- `getLine1Number()` на многих прошивках пуст — фолбек: ручной ввод.
- OEM AutoStart (Xiaomi/Samsung/Realme): нужно включить приложение в «Автозапуск/без ограничений фона» в настройках батареи.
- `Force-stop` убивает сервис до перезагрузки — чинит `BOOT_COMPLETED`.
- `deliveryIntent` может не прийти (зависит от оператора).

## Верификация плана
- `./gradlew :app:assembleDebug` → `app-debug.apk`
- Установить на устройство, ввести номер, Старт → логи «опрос», при запросе в Shop `POST /sms/request-otp` → SMS уходит, статус меняется, в Shop `verify-otp` работает.
